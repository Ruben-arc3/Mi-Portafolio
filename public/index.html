WEBGITHUB

Raíces del Caribe

Plataforma web · artesanías del Caribe colombiano

Plataforma para descubrir y comprar artesanías del Caribe colombiano, conocer a sus creadores y explorar las historias y tradiciones detrás de cada pieza.

  • Frontend: React, TypeScript, Vite y CSS.
  • Backend: API en Node.js y Express con TypeScript.
  • Base de datos: PostgreSQL, conectada con pg.
  • Autenticación: tokens JWT y contraseñas protegidas con hash bcrypt.

TecnologíasReact · TypeScript · Vite · CSS · Node.js · Express · PostgreSQL · JWT · bcrypt
